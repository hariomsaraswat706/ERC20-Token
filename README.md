# Hariom Token (HT)

## Project Description
Hariom Token is a custom ERC20-style token smart contract
developed using Solidity.

## Technology Used
- Solidity
- Remix IDE
- Hardhat 

## Features
- Check token balance
- Transfer tokens
- Mint new tokens
- Burn tokens
- Approve token spending
- Check allowance
- Transfer tokens using transferFrom

## Access Control
Only the owner can mint and burn tokens.
